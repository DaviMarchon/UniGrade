# UniGrade - Gestor de Horários Acadêmicos

O **UniGrade** é uma aplicação web focada na organização da rotina universitária. Ele permite que o estudante configure sua grade horária de forma dinâmica, cadastre matérias com cores personalizadas e gerencie datas de provas e trabalhos de maneira centralizada. Focado principalmente em universitários que estudam no período vespertino/noturno



## 🚀 Funcionalidades

- **Gerenciamento de Disciplinas:** Adicione matérias e o sistema gera automaticamente uma cor exclusiva para cada uma.
- **Grade Horária Interativa:** Clique nos horários para vincular as matérias cadastradas.
- **Sincronização de Tarefas:** Ao adicionar uma prova em uma matéria, ela aparece automaticamente em todos os horários daquela disciplina na semana.
- **Persistência de Dados:** Utiliza o `LocalStorage` para que suas informações não sumam ao fechar o navegador.
- **Contagem Regressiva:** O sistema calcula quantos dias faltam para os seus eventos acadêmicos.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias fundamentais da Web:

* **HTML:** Estrutura "principal" da aplicação.
* **CSS:** Design moderno com variáveis, Flexbox e Grid.
* **JavaScript:** Lógica de manipulação do DOM, cálculos de data e armazenamento local.
